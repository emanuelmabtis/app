# Gerador de Currículo Personalizado (Sem Integração)

Aplicação estática em PT-BR para montar currículo ATS-friendly a partir de formulário, com três estratégias:

- **Modo A**: geração direta por template inteligente.
- **Modo B**: geração de prompt para copiar e colar no ChatGPT.
- **Modo C**: híbrido (currículo direto + prompt opcional).

## Como usar

Abra `index.html` no navegador, preencha os campos e clique em **Gerar currículo + prompt**.
